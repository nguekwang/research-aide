# Titles

The owner's rule for every project of theirs (the website, Languer Map, linguasim, phrase-marker-gen, Corpus Hub and any later one).

- End every page title with ` by yoshi`: one space, then `by yoshi` in lowercase, as the last words. Example: `Language families · Language Atlas by yoshi`.
- "Page title" means the HTML `<title>` and any title set by a script (`document.title`). Add it once, at the end of the whole title, not after each part.
- The visible brand in the page header keeps its current text.
- A new page or a new project gets the suffix from the start.
