# English first

Every repository should read as one whose first language is English.

- Write everything in English: code comments, docstrings, config and YAML comments, workflow files, commit messages, pull request titles and descriptions, rule files and docs.
- Other languages appear only as content (for example a page's text in that language, sample text in a paper), personal names (such as `松浦 義広`) and language names in a language menu.
- This covers repository contents only. Chat with the owner is in Japanese (see `working-with-the-owner.md`).
