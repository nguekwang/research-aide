# No guide needed

The owner's rule, for every site and tool with an interface (Lang Log, the personal site and any later one): anyone can use every feature from the first visit, without a guide.

- No Get started page, guide, tour, tutorial, onboarding popup or help text that explains how to use the interface.
- Design each control so the screen itself shows what it does and how to use it: controls in view rather than hidden gestures or menus, the patterns visitors already know from other sites, and a result that shows at once.
- When a feature seems to need explaining, change its design instead. If the new design needs new wording, ask the owner for it (`only-what-was-asked.md`).
