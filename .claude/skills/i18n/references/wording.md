# The wording

1. Use the owner's own words. If the owner gave none, write a draft in the languages the owner writes on that site (`references/sites.md`), show it in the thread (on the card and in a code block), and wait for approval before it goes into a pull request.
2. Before showing a draft, check it against the site's rules: on Lang Log no source names, no record kinds, and "Languoids" stays in English (`interface-text.md`); on every site no counts or limits typed into the text (`generated-values.md`).
3. Write nothing the owner did not ask for: no descriptions, help text or placeholders such as "coming soon" (`only-what-was-asked.md`).
