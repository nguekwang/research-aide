# The translations

1. Who writes each language is the site's rule (`references/sites.md`). The owner writes or approves some languages; the others are machine translated, by Claude in the same pull request on one site and by a workflow on the other. Where a workflow translates the changed English, do not hand-translate those languages.
2. Translate the meaning, not word by word, in the formal wording each language's interface or official documents use. Keep every placeholder, in the place the language's word order needs.
3. Punctuation, brackets, quotation marks, list separators and digits follow that language's current official documents (`languages.md`), as the site's rule files record them. Never convert notation in whole strings at build time.
4. A name with no proper translation, product and project names, and notation such as `SVO` or `CEFR` keep the English text, as the site's rules list them.
