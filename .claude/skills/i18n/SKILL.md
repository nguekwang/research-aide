# Text in every language

The rules live in `languages.md`, `only-what-was-asked.md` and `generated-values.md` of `research-aide`, and in each site's own rule files; this skill only puts the steps in order and points to them. If a step here and a rule file disagree, the rule file wins: fix this skill in the same pull request. Data quoted from a source (names, titles, citations, codes) is not page text and is never translated.

## Steps

Read each file below, in full, at its step. Every step is required.

1. The site's own facts (where each language's text lives, the language list, who writes which language, the check): `references/sites.md`.
2. The wording: `references/wording.md`. Without the owner's own words or an approved draft, stop here.
3. The keys in every language file: `references/keys.md`.
4. The translations: `references/translations.md`.
5. The checks and the look: `references/checks.md`.
6. The pull request: `references/pull-request.md`.
